# License and redistribution status

The official [et-FCW repository](https://github.com/hawkinglai/et-FCW) has an MIT [LICENSE.txt](LICENSE.txt), retained in this release branch with its original author attribution. The separately preserved historical `reconstruction/` snapshot has no located top-level license of its own, so its exact redistribution status should still be confirmed against the official repository and source lineage. A license in a bundled PointNet2 subproject does not automatically cover unrelated components.

The corrected GeoPCSD source under `experiments/` is derived from project code with a one-line algorithmic correction and path-only loader substitutions. The official MIT grant and the project owner's instruction to publish this branch support this release; the exact lineage of every historical copy has not been independently established. Preserve the upstream copyright notice. Do not treat this as permission to redistribute bundled third-party code or data under the same terms.

Datasets, cached point clouds and the attached paper PDF are excluded. Their terms require separate review. The paper metadata in [CITATION.cff](CITATION.cff) is a citation, not a source-code or dataset license.
